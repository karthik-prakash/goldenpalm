# Golden Palm - Henna by Shruthi 🌿✋

A beautiful, fully interactive website for **Golden Palm — Henna by Shruthi**, a professional Mehendi artist.

## 🌐 Live Site
👉 [Visit Website](https://yourusername.github.io/golden-palm/)

## ✨ Features
- 🎨 Stunning hero section with animated counters
- 📖 About section with artist story
- 💍 6 service categories (Bridal, Baby Shower, Festival, Arabic, Indo-Western, Kids)
- 🖼️ Filterable gallery with lightbox viewer
- 💰 Transparent pricing packages
- ⭐ Client testimonials slider
- 📱 WhatsApp integration for bookings
- 🔧 Admin panel to upload/manage gallery
- 📱 Fully responsive design
- ✨ Smooth scroll animations

## 🛠️ Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- No frameworks — lightweight & fast
- Local Storage for gallery management
